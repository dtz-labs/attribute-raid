ATTRIBUTE RAID

A River Raid-style game for the ZX Spectrum. This page always runs the latest TAP built from main on an emulated Timex TC2068 by default — the dedicated hi-colour build - with the TC2048 and the plain Spectrum 128K a click away. The AY sound effects ported from the Atari 2600 original are audible on all three. Press the ▶ button on the display to start — the game boots with AY sound (browsers only allow audio after that click).

O/P — steer   Q — fast   A — slow   SPACE — fire   R — new game
…or plug in a gamepad / joystick — the game reads it as a Kempston (press a button on the pad so the browser reveals it)

Timex TC2068 Timex TC2048 Spectrum 128K

The Timex versions run on our fork of JSSpeccy 3, which adds the TC2048 and TC2068; stock JSSpeccy has no Timex video modes, so until now the hi-colour build could only be downloaded. Both TAPs are also in the releases.

Emulation by JSSpeccy 3 (GPL-3), in the dtz-labs fork with Timex support.
