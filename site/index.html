ATTRIBUTE RAID

A River Raid-style game for the ZX Spectrum. This page always runs the latest TAP built from main on an emulated Spectrum 128K or Timex, so the AY sound effects ported from the Atari 2600 original are audible. Press the ▶ button on the display to start — the game boots with AY sound (browsers only allow audio after that click).

O/P — steer   Q — fast   A — slow   SPACE — fire   R — new game

☕ Sponsor dtz-labs — support new ZX Spectrum software

Spectrum 128K Timex TC2048 Timex TC2068

The Timex builds are the dedicated hi-colour version, playable here now — the emulator below is our fork of JSSpeccy 3, which adds the TC2048 and TC2068. Both TAPs are also in the releases.

Emulation by JSSpeccy 3 (GPL-3), in the dtz-labs fork with Timex support.
