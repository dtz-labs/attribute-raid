ATTRIBUTE RAID

A River Raid-style game for the ZX Spectrum. This page always runs the latest TAP built from main on an emulated Spectrum 128K, so the AY sound effects ported from the Atari 2600 original are audible. Press the ▶ button on the display to start — the game boots with AY sound (browsers only allow audio after that click).

O/P — steer   Q — fast   A — slow   SPACE — fire   R — new game

☕ Sponsor dtz-labs — support new ZX Spectrum software

The dedicated Timex TC2048/TC2068/TS2068 hi-colour build is not playable here (JSSpeccy has no Timex video modes) — grab it from the releases.
